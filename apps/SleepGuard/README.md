# 🛡️ SleepGuard

极简、原生的 macOS 状态栏应用，用于**实时监控与排查阻止外接屏熄屏休眠的顽疾进程**。

---

## 🎯 痛点背景

很多使用 Mac 外接显示器（如 Type-C / 雷电4 拓展坞 / HDMI / DP）的用户常常遇到一个隐蔽问题：
- Mac 达到空闲休眠时间后，**外接屏幕无法黑屏待机，而是持续常亮在锁屏界面**；
- 这是因为某些应用（如某些游戏启动器、视频播放器、会议软件等）在后台创建了系统的 `PreventUserIdleDisplaySleep`（阻止屏幕空闲休眠）断言，但没有及时释放。
- 传统排查方式需要打开终端运行复杂的 `pmset -g assertions` 并逐行阅读分析，费时费力。

`SleepGuard` 正是为了解决这一痛点而设计的开箱即用轻量工具。

---

## ✨ 核心特性

- **极简状态显示**：常驻顶部菜单栏，仅有两个清晰状态：
  - `💤 正常`：当前无任何应用阻止屏幕息屏，超时后将正常熄屏待机。
  - `🛑 屏常亮`：检测到有进程阻止屏幕熄灭。
- **一键排查定位**：点击图标即可在下拉菜单中直接看到是哪个应用（包括 PID、应用名、阻碍时长）。
- **一键强制结束**：点击下拉菜单中的顽疾进程，弹出确认框即可直接杀掉（`kill -9`），瞬间恢复正常休眠。
- **纯原生零依赖**：基于 Swift 原生编写，无第三方依赖，内存占用极低（< 15MB），CPU 占用趋近于 0。

## 🔨 编译与安装

### 方式一：编译并自动安装到 `/Applications`（推荐）
```bash
chmod +x build.sh
./build.sh install
```

### 方式二：仅编译本地产物
```bash
./build.sh
# 编译完成后可在当前目录获得 SleepGuard.app
```

---

## ⚙️ 开机自启设置（可选）

如需开机自动常驻监控，可在 macOS 中设置：
1. 打开 **系统设置** -> **通用** -> **登录项与扩展**；
2. 在 **“登录时打开”** 列表中点击 `+` 号；
3. 选择 `/Applications/SleepGuard.app` 添加即可。
